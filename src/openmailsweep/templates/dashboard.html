PIPELINE

Independent stages

Gmail batches→hard safety→learned rules→unknown-only queue→local classifier→Pending / action

Intake does not wait for classification. The local model runs in milliseconds; learned-rule mail routes directly to the action queue. The action queue is drained by a configurable concurrent worker pool, while one shared Gmail quota controller keeps aggregate API usage safe. Pending decisions also keep accumulating while you work through the oldest question.
